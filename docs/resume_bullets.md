# Resume Bullets

**SaaS Subscription & Churn Analytics — PostgreSQL, Power BI**

- Built a relational SaaS analytics model spanning 8,000 customer accounts and 190K+ usage, billing, and support records; wrote PostgreSQL workflows for data validation, recurring-revenue KPIs, cohort retention, and churn analysis.
- Engineered customer-health features from product usage, support tickets, and payment history using joins, CTEs, rolling time windows, conditional aggregation, and window functions.
- Designed a four-page Power BI reporting model for MRR/ARR, logo churn, cohort retention, churn drivers, and customer-risk exploration with reusable SQL views and DAX measures.
